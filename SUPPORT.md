# Support

Spaces is community-supported alpha software.

- Use GitHub Discussions for setup questions and design proposals.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security issues.

When reporting a bug, include the Spaces commit, macOS version, desktop or
portal surface, relevant logs with secrets removed, and exact reproduction
steps. Do not post OAuth tokens, pairing codes, device tokens, private
repository content, or full agent transcripts.
